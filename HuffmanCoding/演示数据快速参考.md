## 🎓 演示方案 C：深度演示（10分钟）

### 🔧 初始化阶段（讲解）
```
复制以下内容，按行输入：

T 7
H 5
E 6
R 3
O 4
N 2
S 1
x

讲解：
- 这些是英文常见字母
- T、E、R 出现最频繁
- S 出现最少
- 观察编码表，高频字母编码最短
```

### 📝 编码测试
```
输入文本: THEREFORE

观察：
- MORE = "MORE"（来自 THEREFORE）
- 检查编码长度
- 对比原始长度 (8*5 = 40 bits)
- 计算压缩率
```

### 🔄 解码验证+ 更多测试
```
多个文本测试：
- THERE
- HERO
- STONE
- SHELTER
- THRONE
```

## 💡 演示方案 D：高效率演示（最优压缩）

### 🔧 初始化阶段
```
A 45
B 13
C 12
D 16
E 9
F 5
x

说明：
- A 出现 45% 的频率
- 编码表中，A 应该是最短的 (很可能是 "0")
```

### 📝 编码测试
```
文本列表，逐一测试：

1. 全是频繁字母
   输入: AAABBBDDD
   期望: 低压缩率或无压缩

2. 频率混合
   输入: ABACABAD
   期望: 中等压缩率（～25-35%）

3. 低频字母
   输入: FFFFEEEE
   期望: 高压缩率（～40-50%）
```

### 📊 数据对比
```
输入文本 → 编码结果 → 压缩率

AAAA    → 0000      → 0% (理论)
ABAB    → 01.01...  → 20-30%
BDEF    → 10111...  → 40-50%
```

**总耗时：10-15分钟 ✅**

## ⚠️ 注意事项

### ✅ 可以使用的字符
- 大写字母：A-Z
- 小写字母：a-z
- 数字：0-9 (需要注意占用字符空间)

### ❌ 避免使用
- 中文/特殊符号（暂不支持）
- 空格（会被忽略）
- 控制字符（回车、制表符等）

### 💡 演示最佳实践
1. **先通告**：说明要做什么
2. **边操作**：同时讲解原理
3. **后说明**：解释结果含义
