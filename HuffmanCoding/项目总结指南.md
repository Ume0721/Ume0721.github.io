## 🎓 功能三大模块

### 1️⃣ 初始化模块
```
目的：设置哈夫曼编码表
输入：字符和权值
输出：编码表和树结构展示
```

### 2️⃣ 编码模块
```
目的：演示文本压缩
输入：文本字符串
输出：二进制编码 + 压缩率
```

### 3️⃣ 解码模块
```
目的：验证无损压缩
输入：二进制编码
输出：恢复的原始文本
```

## 💡 演示技巧

### ✅ 高效演示
- 使用 **演示数据快速参考.md** 中的数据
- 避免手动输入，直接粘贴
- 准备 2-3 个不同的演示案例

### ✅ 讲解要点
- 说明频率与编码长度的关系
- 指出压缩率的计算方式
- 强调无损恢复的重要性

### ❌ 常见失误
- ❌ 输入中文或特殊符号
- ❌ 输入不存在于编码表的字符
- ❌ 演示超过 10 分钟显得冗长
