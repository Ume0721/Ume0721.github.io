# ☁️ 在线编译和运行指南

**如果你没有安装 C++ 编译器，也可以在线编译和运行！**

---

## 🌐 在线编译平台

### 方式 1：OnlineGDB (最推荐)

**网址：** https://www.onlinegdb.com/

**步骤：**

1. 打开网站
2. 在左侧编辑器中，**粘贴** `HuffmanSystem.cpp` 的全部内容
3. 屏幕上方选择语言：`C++`
4. 点击 **Run** 按钮
5. 在右侧输出窗口中操作程序

**优点：**
- ✅ 无需安装任何软件
- ✅ 支持用户输入
- ✅ 界面友好
- ✅ 即时编译运行

---

### 方式 2：Ideone

**网址：** https://ideone.com/

**步骤：**

1. 打开网站
2. 粘贴源代码到编辑器
3. 选择语言：`C++ (g++ 11.4.0)`
4. 点击 **Run** 或 **Execute**

---

### 方式 3：Replit

**网址：** https://replit.com/

**步骤：**

1. 点击 **Create Repl**
2. 选择语言：**C++**
3. 粘贴代码
4. 点击 **Run**

---

### 方式 4：GodBolt (代码分析)

**网址：** https://godbolt.org/

**用途：** 查看编译后的汇编代码，适合学习优化

## 🚀 OnlineGDB 使用详解

### 1️⃣ 复制源代码

打开 `HuffmanSystem.cpp` 文件，复制全部内容：

```cpp
// 复制从这里开始
#include <iostream>
#include <vector>
...
// 复制到这里结束
```

### 2️⃣ 粘贴到 OnlineGDB

1. 进入 https://www.onlinegdb.com/
2. 点击编辑器区域（左上角）
3. 按 `Ctrl+A` 全选现有代码
4. 按 `Ctrl+V` 粘贴新代码

### 3️⃣ 准备运行

- 确保右上角显示 **C++**
- 点击 **Run** 按钮（绿色的播放按钮）

### 4️⃣ 使用程序

程序启动后，在下方输出窗口看到菜单：

```
===== 哈夫曼编码系统 =====
1. 初始化
2. 文本编码
3. 序列译码
0. 退出系统

请选择功能(0-3): _
```

在输出窗口输入数据，就像在本地运行一样！

## ⚠️ 注意事项

### 输入格式
- 初始化时，每行输入一个字符和权值，中间用**空格**分隔
- 输入完成后，输入 `x` 结束
- 不支持中文，请使用 A-Z, a-z 字符

### 常见问题

**Q: 复制粘贴不工作？**
```
A: 试试：
   1. 按 Ctrl+A 全选
   2. 按 Delete 删除老代码
   3. 再 Ctrl+V 粘贴新代码
```

**Q: 编译失败？**
```
A: 检查：
   1. 是否正确复制了完整文件
   2. 是否选对了 C++ 语言
   3. 有无多余空格或特殊字符
```

**Q: 卡住不动？**
```
A: 尝试：
   1. 刷新页面
   2. 换个浏览器
   3. 换個在线平台
```

## 📚 本地编译 vs 在线编译

### 本地编译（推荐用于演示）
- ✅ 快速，无网络延迟
- ✅ 支持保存和分享 .exe
- ✅ 可以做复杂交互
- ❌ 需要安装编译器

### 在线编译（推荐用于学习）
- ✅ 无需安装任何东西
- ✅ 支持一键分享代码
- ✅ 适合研究和测试
- ❌ 网络依赖，可能较慢

---

## 🎓 学习建议

1. **第一次学习** → 用在线平台
2. **熟悉后** → 本地编译
3. **现场演示** → 使用 .exe 文件
4. **对比研究** → 两种都试试
