# 哈夫曼编码演示系统 - 使用说明

## 📁 文件清单

```
HuffmanCoding/
├── HuffmanSystem.cpp           # 源代码（核心程序）
├── 编译并运行.bat              # 快速编译脚本（推荐）
├── 使用VS编译.bat              # Visual Studio编译脚本
└── README.md                   # 本说明文档
```

---

## 🚀 快速开始（3步）

### **方案 A：使用编译脚本（最简单 ⭐⭐⭐）**

1. **双击运行** `编译并运行.bat`
2. 脚本会自动检测编译器，编译并运行程序
3. 按照菜单提示操作

**前提条件**：电脑已安装 MinGW（g++）或 Visual Studio

---

## 📋 详细编译步骤

### **方案 B：使用 Dev-C++ （学校机房常用）**

1. 打开 **Dev-C++**
2. `File` → `New` → `Source File`
3. 粘贴 `HuffmanSystem.cpp` 的所有代码
4. 按 **F11** 编译并运行
5. .exe 文件自动在源码目录生成

---

### **方案 C：使用 Visual Studio Code + MinGW**

#### 第一步：安装 MinGW
- 访问 https://www.mingw-w64.org/
- 下载并安装（记住安装路径）
- 将 MinGW 的 `bin` 文件夹添加到系统 PATH

#### 第二步：编译
在 `HuffmanCoding` 文件夹中打开命令行，执行：

```bash
g++ -o HuffmanSystem.exe HuffmanSystem.cpp -std=c++11
```

#### 第三步：运行
```bash
HuffmanSystem.exe
```

---

### **方案 D：使用 Visual Studio**

1. 创建新的 C++ 空项目
2. 将 `HuffmanSystem.cpp` 添加到项目
3. 按 **Ctrl+B** 编译，然后 **Ctrl+F5** 运行

## ⚠️ 常见问题

**Q1: 编译时出现错误 "找不到编译器"**
- A: 安装 MinGW 或 Visual Studio 后重试

**Q2: 运行时出现中文乱码**
- A: 确保终端编码为 UTF-8（Windows 10+ 默认支持）

**Q3: 编码某个字符后显示为空**
- A: 确保输入的字符在初始化时就已经输入过了

**Q4: 如何在 U 盘携带演示？**
- A: 将编译好的 `HuffmanSystem.exe` 复制到 U 盘，在任何 Windows 电脑上直接运行

## 🎓 演示时的要点

1. **展示清晰的输入和输出** - 使用大写字母 (A, B, C) 和整数权重
2. **现场翻译演示** - 让同学随说一串 01，你输入进去展示译码功能
3. **强调算法逻辑** - 解释权值最小的两个节点为什么要合并
4. **对比压缩效果** - 可以提前计算原文本 vs 编码后的数据量对比
