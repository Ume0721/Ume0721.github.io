## 🔧 编译方法速查表

### 自动编译（推荐）

**Windows:**
```
双击 一键启动.bat
```

**Linux/Mac:**
```
bash compile.sh
```

### 手动编译

```bash
# MinGW (Windows)
g++ -o HuffmanSystem.exe HuffmanSystem.cpp -std=c++11
HuffmanSystem.exe

# GCC (Linux)
g++ -o HuffmanSystem HuffmanSystem.cpp -std=c++11
./HuffmanSystem

# Clang (Mac)
clang++ -o HuffmanSystem HuffmanSystem.cpp -std=c++11
./HuffmanSystem

# Visual Studio (Windows)
cl.exe /o HuffmanSystem.exe HuffmanSystem.cpp
HuffmanSystem.exe
```

### 在线编译

访问 https://www.onlinegdb.com/
- 粘贴代码
- 选择语言C++
- 点击Run
