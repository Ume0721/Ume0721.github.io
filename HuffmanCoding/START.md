## 🚀 情况 A：我有 C++ 编译器（推荐）

```
1. 双击 "编译.bat" 文件
2. 等待编译完成
3. 程序自动启动
```

**耗时：30 秒**

### Linux/Mac 用户：最简单的方式
```bash
bash compile.sh
```

**耗时：30 秒**

### 所有平台：Python 方式
```bash
python3 build.py
```

**耗时：30 秒**

## ☁️ 情况 B：我没有编译器

### 在线编译方式（完全免费）

打开：**https://www.onlinegdb.com/**

1. 复制 `HuffmanSystem.cpp` 全部内容
2. 粘贴到网站编辑器
3. 点击 **Run**
4. 在输出窗口操作程序

**耗时：2 分钟**

详见：[在线编译指南.md](在线编译指南.md)
