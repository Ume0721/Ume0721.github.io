# 🎯 哈夫曼编码系统 - 完整演示指南

## 📦 第一步：编译程序

### 方式 1️⃣: Linux/Mac 快速编译
```bash
cd HuffmanCoding
bash compile.sh
```

### 方式 2️⃣: 手动编译（任何系统）
```bash
cd HuffmanCoding
g++ -o HuffmanSystem.exe HuffmanSystem.cpp -std=c++11
```

### 方式 3️⃣: Python 编译脚本
```bash
cd HuffmanCoding
python3 build.py
```

## 📝 第三步：完整演示流程

### 演示场景 1：基础流程演示（5分钟）

#### 输入步骤
```
===== 哈夫曼编码系统 =====
1. 初始化
2. 文本编码
3. 序列译码
0. 退出系统

请选择功能(0-3): 1
```

选择 `1` 进入初始化

#### 输入演示数据
程序会提示：`输入字符和权值 (格式: 字符 权值, 如: A 5)，输入"x"结束`

输入以下数据（可直接复制粘贴）：
```
A 5
B 3
C 2
D 4
x
```

#### 第一阶段完成
程序会显示：
```
[哈夫曼编码表]
-------------------
字符  权重  编码
A     5    0
B     3    10
C     2    110
D     4    111
-------------------
```

### 演示场景 2：文本编码演示（2分钟）

选择 `2` 进行编码

输入文本：
```
ABACABA
```

程序输出：
```
原始文本: ABACABA
编码结果: 010010110010
编码长度: 12 bits
原始长度: 56 bits (7字符×8)
压缩率: 78.57%
```

### 演示场景 3：序列译码演示（2分钟）

选择 `3` 进行译码

输入二进制码：
```
010010110010
```

程序输出：
```
编码序列: 010010110010
译码结果: ABACABA
译码成功!
```

## 💡 演示技巧 & 注意事项

### ✅ 成功演示的秘诀：

1. **控制演示时间**
   - 初始化阶段：1-2分钟
   - 编码演示：1分钟
   - 译码演示：1分钟
   - 总计：3-4分钟紧凑演示

2. **选择合适的演示数据**
```
简单数据（适合快速演示）：
A 10
B 5
C 3
D 2

复杂数据（展示算法复杂性）：
A 45
B 13
C 12
D 16
E 9
F 5
```

3. **编码时使用可视化文本**
   - ✅ 好：`HELLO`、`ABCD`、`AAAA`
   - ❌ 避免：特殊字符、空格、数字（需转换）

4. **实时讲解编码过程**
   - 解释哈夫曼树的构建过程
   - 指出高频字符编码更短
   - 演示压缩效果

### 📊 数据效果对比：

| 场景 | 输入 | 输出 | 压缩率 | 说明 |
|------|------|------|--------|------|
| 均匀频率 | ABCD | 0110 | 0% | 理想情况：无压缩收益 |
| 不均匀频率 | AAABBD | 000100 | 33% | 现实情况：明显压缩 |
| 高度不均匀 | AAAAABBC | 00000100 | 50% | 最优情况：最大压缩 |

## 🔧 常见问题排查

### Q: 编译时提示 "g++ not found"
**A:** 安装编译器
```bash
# Ubuntu/Debian
sudo apt-get install build-essential

# macOS
brew install gcc

# 或使用在线编译: https://www.onlinegdb.com/
```

### Q: 输入特殊字符出错
**A:** 仅支持可打印的 ASCII 字符（A-Z, a-z）

### Q: 编码长度显示为 0
**A:** 检查输入的文本中是否包含未初始化的字符

### Q: 程序立即退出
**A:** 检查是否选择了 `0` 退出选项
