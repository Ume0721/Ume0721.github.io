3. **等待完成** → 自动编译并运行

### 🐧 方式 2：Linux/Mac 用户

**终端中执行：**
```bash
cd HuffmanCoding

# 任选其一
bash compile.sh        # 方式 A：执行脚本
make run              # 方式 B：使用 Makefile
g++ -o HuffmanSystem.exe HuffmanSystem.cpp -std=c++11 && ./HuffmanSystem.exe  # 方式 C：手动编译运行
```

**需要：**
- Python 3.6+
- g++ 编译器

**执行：**

## ✅ 检查清单

编译前，请确认：

- [ ] 已安装 C++ 编译器 (g++)
  - Windows: MinGW 或 Visual C++
  - Linux: `sudo apt-get install build-essential`
  - Mac: `brew install gcc`

- [ ] 在正确的目录 (`HuffmanCoding` 文件夹)

- [ ] 源文件存在 (`HuffmanSystem.cpp`)

---

## 🐛 故障排查

### ❌ 问题：`g++ not found`
```bash
# Ubuntu/Debian
sudo apt-get install build-essential

# macOS
brew install gcc

# Windows
# 下载 MinGW: https://www.mingw-w64.org/
```

### ❌ 问题：编译失败
```bash
# 尝试完整编译命令
g++ -o HuffmanSystem.exe HuffmanSystem.cpp -std=c++11 -v

# 查看详细错误信息
```

### ❌ 问题：程序立即退出
```
原因：选择了 0 (退出)
解决：选择 1、2 或 3
```

### ❌ 问题：编码无效
```
检查：
- 输入的文本中所有字符是否都已初始化
- 是否包含特殊符号或中文（暂不支持）
```
