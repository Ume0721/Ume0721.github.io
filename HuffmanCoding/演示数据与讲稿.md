## 📊 数据分析

### 上表的哈夫曼编码（方案1）

权值统计：
- A: 5
- B: 2  (最小)
- C: 9  (最大)
- D: 4

构造过程：
```
第1步：合并B(2)和D(4) → 节点E1(6)
第2步：合并A(5)和E1(6) → 节点E2(11)
第3步：合并C(9)和E2(11) → 根节点(20)
```

最终树結構：
```
        root(20)
       /        \
     C(9)      E2(11)
             /        \
           A(5)       E1(6)
                     /      \
                   B(2)     D(4)
```

对应编码：
- A: 10 (左，右)
- B: 001
- C: 0
- D: 011

## 💡 演讲要点提示

1. **打开程序时**：展示源代码，说明这是用C++编写的
2. **初始化时**：强调"权值越小的字符编码越长"，这是哈夫曼算法的精妙之处
3. **编码时**：指向编码表，让观众理解每个字符是如何被替换的
4. **译码时**：演示如何从根节点顺着01序列走到叶子节点
5. **结尾总结**：讲解实际应用（JPEG、MP3、ZIP压缩等）
