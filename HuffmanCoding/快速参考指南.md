## ⚡ 30秒快速开始

### **方案1：Windows用户（最简单）**

1. **双击** `一键启动.bat`
2. 程序会自动检测编译工具、编译、运行
3. 完成！

---

### **方案2：Mac/Linux用户**

```bash
bash compile.sh
```

---

### **方案3：没有编译工具**

访问 [OnlineGDB](https://www.onlinegdb.com/)：
1. 粘贴 `HuffmanSystem.cpp` 代码
2. 语言选择 C++
3. 点击 Run 运行

## ❌ 常见错误及解决

| 错误 | 原因 | 解决 |
|-----|------|------|
| 找不到编译器 | 没装C++开发环境 | 装MinGW或VS |
| 编译失败 | 代码有误 | 检查HuffmanSystem.cpp是否完整 |
| 乱码 | 终端编码问题 | 用"一键启动.bat"解决 |
| 无法运行 | 权限问题 | 右键→属性→兼容性→以管理员运行 |
