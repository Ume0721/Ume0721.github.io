【第一步】选择你的平台，执行对应命令

  Windows 用户（最简单）→ 双击 "一键启动.bat"

  无编译环境             → 到 https://www.onlinegdb.com/ 在线编译

  ===== 哈夫曼编译码系统 =====
  1. 初始化(输入字符与权值)
  2. 文本编码(Text -> 0101)
  3. 序列译码(0101 -> Text)
  0. 退出系统
  ============================

【第三步】按照提示操作，完成演示

  选项菜单：按数字 1/2/3/0 选择功能
  字符权值：输入要编码的字符和权值，例如 "A 5"

🚀 分钟开始的三种方法

【方法1】Windows用户 - 最简单
  ① 双击 "一键启动.bat"
  ② 程序自动编译并运行
  ③ 完毕！

【方法2】有编译器的用户 - 标准方法
  命令行执行:
    g++ -o HuffmanSystem.exe HuffmanSystem.cpp -std=c++11
  然后运行:
    HuffmanSystem.exe    (Windows) 或 ./HuffmanSystem (Linux/Mac)

【方法3】没有编译器 - 在线编译
  ① 打开 https://www.onlinegdb.com/
  ② 复制 HuffmanSystem.cpp 代码到网站
  ③ 点击 Run 按钮
  ④ 在网站提供的输入框输入数据

❓ 常见问题快速解决

Q1: 双击 bat 文件没反应？
  A: ① 用命令行方式运行：在此目录打开 cmd 或 PowerShell
     ② 复制黏贴命令运行（见【方法2】）
     ③ 尝试在线编译（见【方法3】）

Q2: "找不到编译器" 错误？
  A: ① 安装 MinGW 或 Visual Studio
     ② 或用在线编译器 https://www.onlinegdb.com/

Q3: 中文显示乱码？
  A: ① 用 "一键启动.bat" 已解决
     ② 或在命令行输入：chcp 65001

Q4: 程序打开就闪退？
  A: ① 用命令行运行（不要双击 exe）
     ② 或修改代码末尾添加 cin.get()

更多问题？→ 查看 "编译常见问题.md"
